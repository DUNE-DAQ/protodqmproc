# protodqmproc
DQM Prototyping

## Build

To build with the standard [DUNE DAQ Buildtools](https://dune-daq-sw.readthedocs.io/en/latest/packages/daq-buildtools/), add `"protodqmproc"` at the end of your `sourcecode/dbt-build-order.cmake` file before runnning `env.sh` command from the the DAQ build instructions.
